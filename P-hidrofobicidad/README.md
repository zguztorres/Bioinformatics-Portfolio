# Biofertilizer Analysis Pipeline (El Salvador 2023)

## Description
This project focuses on the critical analysis and redesign of biological visualizations derived from a survey on PGPB biofertilizer usage in graminaceous crops. The study moves beyond standard descriptive summaries, reconstructing the analysis from raw data to produce robust, reproducible visualizations that enable accurate comparisons[cite: 4].

## Key Features
* **Reproducible Pipeline:** A Jupyter Notebook detailing every step, from raw data ingestion to final data cleaning and visualization.
* **Rigorous Visuals:** Redesign of standard charts into perceptually robust graphics (boxplots, Cleveland dot plots, and divergent Likert bars) following the Grammar of Graphics[cite: 4].
* **Data Cleaning:** Explicit documentation of normalization, outlier handling, and semantic cleaning of free-text responses to ensure biological data integrity[cite: 4].

##  Tech Stack
* **Language:** Python
* **Data Analysis:** `pandas`, `numpy`, `scipy`
* **Visualization:** `altair`

## How to explore
1. Clone this repository.
2. Open the `.ipynb` notebook to see the step-by-step pipeline. The figures are rendered automatically.
