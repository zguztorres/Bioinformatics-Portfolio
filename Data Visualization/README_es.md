# Pipeline de Análisis de Biofertilizantes (El Salvador 2023)

## Descripción
Este proyecto se centra en el análisis crítico y rediseño de visualizaciones biológicas derivadas de una encuesta sobre el uso de biofertilizantes PGPB en cultivos de gramíneas. El trabajo trasciende los resúmenes descriptivos básicos, reconstruyendo el análisis desde el dato crudo para generar visualizaciones reproducibles que permitan comparaciones precisas[cite: 4].

## Características Principales
* **Pipeline Reproducible:** Un Jupyter Notebook que detalla cada paso, desde la ingesta de datos hasta la limpieza y visualización final.
* **Rigor Perceptivo:** Rediseño de gráficos convencionales hacia visualizaciones perceptualmente robustas (boxplots, Cleveland dot plots y barras divergentes) siguiendo la Gramática de los Gráficos[cite: 4].
* **Limpieza de Datos:** Documentación explícita de los procesos de normalización, manejo de valores atípicos y limpieza semántica de respuestas de texto libre para garantizar la integridad de los datos biológicos[cite: 4].

##  Stack Tecnológico
* **Lenguaje:** Python
* **Análisis de Datos:** `pandas`, `numpy`, `scipy`
* **Visualización:** `altair`

## Cómo explorar el proyecto
1. Clona este repositorio.
2. Abre el notebook `.ipynb` para visualizar el pipeline paso a paso. Las figuras se renderizan automáticamente.
